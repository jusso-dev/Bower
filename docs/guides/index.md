## Know who can make a change

Viewers can read status. Operators prepare configuration changes. Approvers review
requests. Administrators manage setup and lifecycle actions. Some actions require
a different person to approve them. The API enforces access even if someone opens
a technical page directly. Read the [role model](../security/management-identity-and-rbac.md).
